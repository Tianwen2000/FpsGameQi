# 🎮 天问 (Tianwen) - 纯代码驱动的 WebGL FPS

> **“一个可以‘吃掉’你手机电量与散热器的单文件 HTML5 3D FPS 游戏。”**

**《天问》** 是一款基于原生 `Three.js` 构建的第一人称射击游戏。本项目最硬核的地方在于其 **“零外部资产”** 的单文件架构——不需要下载任何图片、3D 模型或音频文件。所有的场景建筑、敌人机甲、武器模型，甚至墙面上的文字贴图，均由 JavaScript 代码在本地实时程序化生成（Procedural Generation）。

## ✨ 核心特性

- 📦 **极致的单文件架构**：整个游戏仅包含一个 `.html` 文件，抛弃了繁重的资源包和网络请求。
- 🎨 **程序化生成（Procedural Generation）**：使用 Canvas 实时绘制 UI 和贴图（包括集装箱编号、标语），利用代码拼接几何体构建出枪械与机械敌人。
- 💡 **次世代 WebGL 渲染**：内置 PBR 材质、动态阴影、体积光（God Rays）、屏幕空间环境光遮蔽（AO）以及泛光（Bloom）特效。
- 🧠 **完整的敌人 AI**：基于 AABB 碰撞、射线检测与寻路算法实现的“机械飞鸥”与“机械猎犬”实体状态机。
- 📱 **多端适配**：完美支持 PC 端键鼠操作与移动端双摇杆触屏操作。

### 💻 PC 端 (键盘 + 鼠标)

| :--- | :--- |

## ⚠️ 性能警告 (必读)

**“在电脑上惊艳四座，在手机上疯狂发烫。”**

由于本项目的所有光影、物理计算和贴图生成均在**本地浏览器**中实时“硬算”得出（完全没有云端服务器参与渲染），它极度消耗客户端的 GPU 和 CPU 资源。
- **在 PC 上**：建议使用独立显卡或较新的核显游玩，体验最佳。
- **在手机上**：如果遇到明显卡顿或掉帧，请进入游戏主菜单的【设置】->【画面质量】，**手动将画质调至“低”（Low）**，并准备好散热背夹。
